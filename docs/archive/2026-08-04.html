Proteinum、AI受発注エージェント「ECPRO BRAIN」がYahoo!ショッピングと連携開始

2026年8月4日発表

株式会社Proteinumは、EC事業者・運用代行会社向けのAIエージェント型SaaS「ECPRO BRAIN」について、 新たにYahoo!ショッピングとの連携を開始したと発表した。既存の楽天市場・Amazonに加え、Shopifyとも 連携済みで、複数モールの売上集計、販売戦略の立案支援、タスク管理、CSVアップロードなどを単一の ダッシュボードから行えるようにする。国内主要ECモールの一元管理ニーズに対応する狙い。

出典: 株式会社Proteinum 公式プレスリリース（PR TIMES）

三菱重工業とGreen AI、産業分野のエネルギー効率改善で協業開始

2026年8月3日発表

三菱重工業株式会社と株式会社Green AIは、産業分野のエネルギー効率改善に向けた「ソリューション利用 パートナー契約」を締結したと発表した。三菱重工が持つCO2削減・製造技術のノウハウと、Green AIが 提供する約5,700件の脱炭素施策データベースを持つAIシステムを組み合わせ、商工組合中央金庫（商工中金） を通じて中堅・中小企業の省エネと経済性の両立を支援する。SaaS単体の新製品ではなく、企業間の 協業・販売パートナーシップの発表である点に留意されたい。

出典: 株式会社Green AI 公式プレスリリース（PR TIMES）

B. AI/LLM・開発ツール

Alibaba、24兆パラメータ級の新モデル「Qwen3.8-Max」を発表二次情報

2026年8月3日発表

Alibabaは、総パラメータ数2.4兆の新モデル「Qwen3.8-Max」を発表し、AlibabaのAIプラットフォーム 「Qwen」上でAPI提供を開始した。コーディングやオフィス業務向けの性能を重視しており、新設の オフィス業務エージェント「Qwen Office」にも組み込まれている。オープンウェイト版のQwen3.8-Maxと、 軽量版のQwen3.8-27Bは来週の公開を予定しているという。Alibaba公式ブログ（qwen.ai）はJavaScript 描画のため本文を直接確認できず、本項目は複数の海外メディア報道をもとに記載している。

出典: TechNode（一次情報: Alibaba Qwen公式ブログ、本文未取得）

GitHub、GitLabからの移行ツール「GitHub Enterprise Importer」を一般提供開始

2026年8月3日公開

GitHubは、gitlab.comおよびGitLab Self-ManagedからGitHub Enterprise Cloudへのリポジトリ移行を 支援する「GitHub Enterprise Importer」を一般提供（GA）した。コマンドラインの拡張機能 `gh gl2gh` を用いて単体・一括での移行が可能で、移行アーカイブの保管先としてGitHub管理のストレージ と、利用者自身のAWS S3・Azure Blobのいずれかを選択できる。GitHub Enterprise Serverへの移行は 現時点で未対応。

出典: GitHub Changelog（公式）

GitHub、Triageロールでもissue作成制限をバイパス可能に

2026年8月3日公開

GitHubは、リポジトリのissue作成を「コラボレーターのみ」に制限している場合でも、Triageロールを 持つユーザーがissueを作成できるよう権限範囲を拡張した。従来はWrite権限を持つユーザーに限られて いたが、信頼できるTriage権限者にも作成を許可することで、モデレーションと貢献のしやすさの両立を 図る。

出典: GitHub Changelog（公式）
