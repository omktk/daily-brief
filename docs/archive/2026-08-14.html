チャットプラス、顧客対応後の業務まで自動化する「AI AgentPlus Pro」を提供開始

2026年8月13日公開

チャットプラス株式会社は、AIエージェントサービスの新版「AI AgentPlus Pro」の提供を 開始したと発表した。従来の問い合わせ対応にとどまらず、回答後のデータ入力・CRM登録・ 担当者通知といった後続業務までを一連のプロセスとして自動実行する点が特徴。 Salesforceやkintoneなど外部システムとのノーコード連携にも対応し、企業ごとの 業務フローに合わせて設定できるとしている。

出典: PR TIMES（チャットプラス株式会社）

デジタルガレージ、エージェンティックコマース統合基盤「DG Agentic One」を提供開始

2026年8月13日公開

株式会社デジタルガレージと株式会社DGビジネステクノロジーは、生成AIによる購買行動の 変化に対応する統合プラットフォーム「DG Agentic One」の提供開始を発表した。AI向けの データ変換・生成（DataFeed）、AI検索での商品推奨対策（GEO）、商取引プロトコル対応 ゲートウェイ（MCP）、次世代EC構築（Commerce）、決済（Payment・開発中）の5機能を 統合する国内初のソリューションとしており、2030年までに国内エージェンティック コマース市場（推定約15兆円）のうち3兆円規模の流通額支援を目指すとしている。

出典: PR TIMES（株式会社デジタルガレージ）

B. AI/LLM・開発ツール

Google、コーディング・エージェント向け新モデル「Gemini 3.7 Flash」を発表

2026年8月13日公開

Googleは公式ブログで、前モデル「Gemini 3.6 Flash」からわずか3週間で後継モデル 「Gemini 3.7 Flash」を発表したと明らかにした。ソフトウェアエンジニアリングや Web開発のワークフローで精度が向上しており、FrontierCode 1.1のスコアは34.4%から 43.6%へ、DeepSWE v1.1は49.0%から65.3%へ改善したとしている。価格は2026年末まで 3.6 Flashの半額（入力100万トークンあたり0.75ドル・出力3.75ドル）。Gemini API・ AI Studio・Gemini Sparkなどから利用できる。

出典: Google公式ブログ

GitHub Copilotで「Gemini 3.7 Flash」が利用可能に

2026年8月13日公開

GitHubは公式チェンジログで、Googleの新モデル「Gemini 3.7 Flash」がGitHub Copilotで 利用可能になったと発表した。早期テストではWeb・アプリ開発やエージェント型コーディング ワークフローの改善が確認されているという。対象はCopilot Pro・Pro+・Max・Business・ Enterpriseの各プランで、VS Code・Visual Studio・JetBrains・Xcodeなど複数エディタに 対応する。Business・Enterpriseでは管理者による事前のポリシー有効化が必要で、 段階的なロールアウトが進行中としている。

出典: GitHub Changelog

Cursor、Cloud Agentsの起動を高速化する「builds」機能を導入

2026年8月13日公開

Cursorは公式チェンジログで、開発環境を事前にバックグラウンドで準備しておく 「builds」機能を発表した。エージェントは毎回ゼロから環境構築する代わりに、 準備済みの環境から起動できるようになる。ビルドが成功するたびに以後のエージェントの 起点として使われ、内部計測では環境起動が最大10倍、最初のトークン出力までの時間が 3倍高速化したという。Cloud Agentsの利用者は追加費用なしで利用でき、 ビルド履歴とログはダッシュボードから確認できる。

出典: Cursor公式チェンジログ

VS Code 1.133、Claudeセッションのモデル切り替えなどを追加

2026年8月12日公開

Microsoftは「Visual Studio Code 1.133」をリリースした。チャット中にAnthropicモデルと Copilotモデルのグループをターンごとに切り替えられるようになったほか、 設定を有効にすればGitHubへサインインせずAgentsウィンドウを開けるようになり、 既存のClaude APIキー利用者は追加のサインイン手順が不要になった。このほか、 長い会話でも直前のやり取りが画面上部に固定表示される「スティッキースクロール」や、 ローカルのHTML変更をプレビューへ自動反映する機能も追加された。

出典: Visual Studio Code公式アップデートノート
