GitHub Copilot、コードレビューでの「Agent Skills」「MCPサーバー連携」が一般提供開始

2026年7月29日公開

GitHubは、Copilotのコードレビュー機能において、チーム独自のツール・基準を組み込める 「Agent Skills」（.github/skills配下にSKILL.mdを追加）と、既存のイシュートラッカー等 外部ツールから読み取り専用でコンテキストを取得する「MCPサーバー連携」の一般提供を開始した。 Copilot Pro / Pro+ / Business / Enterprise の全ユーザーが対象で、レビューコメント生成時に 参照元ツールが表示されるようになる。

出典: GitHub Changelog（公式）

GitHub、Copilot Business/Enterprise向けに新モデルの「デフォルト有効化」ポリシーを導入

2026年7月29日公開

GitHubは、一般提供された新モデルを管理者の手動設定なしに自動で有効化するポリシーを Copilot Business/Enterpriseに導入すると発表した。8月26日から本格適用され、未設定モデルは 「デフォルト継承」状態としてポリシーに従い自動判定される。オープンウェイトモデルやデータ保持契約 対象外のモデルは適用除外。管理者には猶予期間中の設定見直しを推奨している。
