2026年8月6日発表

株式会社アイデアランプは、既存ホームページの保守管理に特化した新サービス「ウェブ担さん Jr.」の 提供を開始したと発表した（サービス開始日は2026年7月31日）。初期費用0円、月額5,000円からで、 基本1営業日以内の更新対応をうたう。他社制作サイトでもドメイン変更なしで乗り換え可能とし、 更新・改修回数は無制限としている。

PR TIMES、タスク・プロジェクト管理SaaS「Jooto」の一般提供終了を発表

2026年8月6日発表

株式会社PR TIMESは、自社運営のタスク・プロジェクト管理ツール「Jooto」について、2027年7月31日 をもって一般提供を終了すると発表した。同日付で新規利用登録・新規有料契約・アップグレード等の 受付を停止し、既存契約ユーザーは終了日まで利用可能。廃止理由として営業損失の継続と競争優位の 未確立を挙げている。なお、トヨタ自動車向け提供分は対象外で継続するとしている。

出典: 株式会社PR TIMES 公式プレスリリース（PR TIMES）

Anthropic、Claude Code v2.1.223をリリース

2026年8月6日公開

Anthropicは開発ツール「Claude Code」の新バージョン2.1.223を公開した。セキュリティ面では、 細工されたコマンドで権限チェックを回避できるBash権限バイパスの脆弱性や、タブ・不可視Unicode文字 でコマンドの一部を隠す手口への対策を修正した。機能面では、GitHub組織単位でマーケットプレイスを 一括許可・ブロックできるワイルドカード指定（`"owner/*"`）を追加し、`/review`を`/code-review` のエイリアスに変更したほか、クラウドセッションからローカルへ継続する`/teleport`ヒントも追加された。

出典: Claude Code 公式チェンジログ

GitHub Copilot、オープンウェイトモデル「Kimi K3」を一般提供開始

2026年8月6日公開

GitHubは、オープンウェイトモデル「Kimi K3」をGitHub Copilotで一般提供開始したと発表した。 エージェント型コーディングでフロンティア級の性能を比較的低コストで提供するとしており、 ホスティングはFireworks AI経由。Copilot Pro・Pro+・Max・Business・Enterprise向けに順次展開され、 料金は入力100万トークンあたり3ドル、出力100万トークンあたり15ドル。Business・Enterprise向けは 既定で無効になっており、管理者が個別に有効化する必要がある。

出典: GitHub Changelog 公式ブログ
