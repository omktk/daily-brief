A. 日本のB2B/バーティカルSaaS・プロダクトマネジメント

経営者向けAI「LoreOS」、社内業務を代行する「AIエージェント」機能を追加

2026年8月21日 16:16発表

株式会社AIXが、経営者向けの企業ナレッジプラットフォーム「LoreOS（ロアオーエス）」に、 営業・財務・議事録整理といった実務を役割別のAIに任せられる新機能「AIエージェント」を 追加した。COO補佐、DXコンサルタント補佐、財務CFO補佐など7種類のプリセット担当AIから 選んで依頼する形式で、定期実行機能も備える。処理はローカルLLM中心で設計されている。

出典: 株式会社AIX 公式プレスリリース（PR TIMES）

B. AI/LLM・開発ツール

Claude Code v2.1.239、コスト見積もりの精緻化とBedrockプロキシ周りの修正を含む更新

2026年8月21日（v2.1.239）

AnthropicのClaude Codeがv2.1.239を公開。`/cost` やステータスラインのコスト推定に 米国リージョン向け推論プレミアムを反映したほか、claude.ai同期プラグインが `name@synced` として区別表示されるようになった。Bedrock利用時のプロキシ経由 ストリーミング不具合の修正や、Cloudセッションの復帰処理の安定化なども含まれる。

出典: Claude Code Changelog（公式）

GitHub Copilot、SlackとMicrosoft Teamsでのエージェント連携をパブリックプレビュー公開

2026年8月21日

GitHubが、Copilotのクラウドエージェントセッションをチャット上から開始できる Slack・Microsoft Teams向けの新統合をパブリックプレビューとして公開した。 チャンネルやスレッドで `@GitHub` にメンションすると、調査・修正・検証を代行し プルリクエストを作成する。作業はサンドボックス内で実行され、リポジトリ管理者は Copilot作成PRへの追加承認を必須にできる。有料プランのCopilot Business/Enterprise向け。

出典: GitHub Changelog（公式）
