A. 日本のB2B/バーティカルSaaS・プロダクトマネジメント

サイオステクノロジー、企業間取引向けCIAM製品「Gluegent Gate CIAM B2B」を提供開始

2026年7月28日 10:47発表（提供開始は8月1日）

サイオステクノロジー株式会社は、IDaaS「Gluegent Gate」の新製品として、取引先・委託先・ グループ会社などの外部ユーザー向けID管理・認証サービス「Gluegent Gate CIAM B2B」を発表した。 経済産業省・内閣官房国家サイバー統括室が2026年度末の開始を予定する「サプライチェーン強化に 向けたセキュリティ対策評価制度（SCS評価制度）」を見据え、社内ユーザー向けID管理（EIAM）では 対応が難しかった外部ユーザーの認証強度ばらつきに対応する。

出典: サイオステクノロジー株式会社 公式プレスリリース（PR TIMES）

エキサイト「FanGrowth」、オロパスの共催ウェビナー施策で商談化率26%を実現

2026年7月28日 10:00発表

エキサイト株式会社は、SEO/LLMOツール「Pascal」を展開する株式会社オロパスによる ウェビナー支援SaaS「FanGrowth」導入事例を公開。立ち上げ直後から共催ウェビナーを軸とした マーケティング施策を展開し、商談化率26%を達成したという。企画・共催先マッチングのノウハウ 獲得のため外部に運営を委ね、社内リソースを商談化に集中させる体制へ移行したと報告している。

B. AI/LLM・開発ツール

Model Context Protocol、正式仕様「2026-07-28」を公開

2026年7月28日公開

MCP運営チームは、プロトコル発表以来最大規模の改訂となる正式仕様「2026-07-28」を公開した。 セッションIDや初期化ハンドシェイクを廃止しリクエストを任意のサーバーインスタンスに ルーティング可能にする「ステートレスコア」への移行、確認応答を要するツール実行を常時接続 なしで扱う「Multi Round-Trip Requests」、OAuth 2.0/OpenID Connectとの整合性を高めた 認可強化などが柱。Tier 1の主要SDKは公開時点で新仕様に対応済みとしている。

出典: Model Context Protocol Blog（公式）

GitHub Actions、悪意の疑いのあるワークフロー実行を承認待ちで保留する機能を導入

2026年7月28日公開

GitHubは、侵害された認証情報を悪用してCI/CD権限を窃取するサプライチェーン攻撃への対策として、 悪意の可能性があると判定されたワークフロー実行を自動的に保留する機能を発表した。書き込み権限を 持つ協力者が認証済みのWebセッションで承認するまで実行されない。ユーザー側の設定は不要で自動適用 されるが、対象は現時点で github.com 上の公開リポジトリのみで、GitHub Enterprise Server は 対象外。

出典: GitHub Changelog（公式）
