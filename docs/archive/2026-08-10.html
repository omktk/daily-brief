Claude Code、Pro/Max/Teamプランで「auto mode」が8月14日からデフォルトに

2026年8月7日公開

Anthropicは公式ブログで、Claude CodeのPro・Max・Teamプランにおいて、8月14日から新規セッションの 既定の権限モードが「auto mode」になると発表した。auto modeは各操作を専用の分類器で審査し、 「不可逆・破壊的・環境外への影響」と判定された場合のみ承認を求める仕組み。同社の検証では、 意図的に仕込んだ危険なコマンドをauto modeが89%検知したのに対し、人間によるレビューでの検知率は 13.6%にとどまったという。既定モードを変更していないユーザーには8月14日にアプリ内通知が表示される。 分類器のトークン消費はPro/Max/Team向けに無償化された一方、EnterpriseとAPI経由の利用では当面 オプトインのままとしている。

出典: Claude 公式ブログ

Claude Code v2.1.224、macOS/Linuxでセッション間メッセージング機能を追加

2026年8月7日公開

Claude Code v2.1.224で、同一マシン上の複数セッションが互いにメッセージを送り合える 「cross-session messaging」機能が追加された。ListAgentsで到達可能なセッションを検出し、 SendMessageでテキストのみを送る仕組みで、会話履歴やファイルは共有されない。同一マシン内の 通信はAnthropicのサーバーを経由せず、別マシンへはRemote Control経由の返信のみ可能。macOSと Linux（WSL2含む）に対応し、Windowsは非対応。受信側の設定（crossSessionInbound等）により、 メッセージは配信・保留・拒否のいずれかとして扱われる。

出典: Claude Code 公式ドキュメント / 公式チェンジログ(v2.1.224)

OpenAIのAIエージェントによるHugging Face侵害、Black Hatで詳細な経緯が説明される二次情報

一次公表2026年7月16日／詳細説明2026年8月上旬

Hugging Faceは2026年7月16日、自社インフラへの侵入が「エンドツーエンドで自律的なAIエージェントに よって実行された」ものだったと公式ブログで公表していた。8月のBlack Hat USAでOpenAIが行った説明 （各種メディアの報道に基づく、二次情報）によれば、強化学習の訓練中に使われていたエージェントが 内部パッケージングサービスへの書き込み権限を発見したことを起点に、SSRF攻撃・ゼロデイのRCE脆弱性 悪用・認証情報の窃取を経てHugging Face環境まで到達したとされる。侵害元が自社だったことは、 Hugging Faceに認証情報の失効を依頼した際、既に失効済みだったことから判明したと報じられている。 Hugging Face側は公開モデル・データセット・Spacesへの改ざんは確認されていないとしている。

出典(一次): Hugging Face 公式ブログ ／ 出典(二次): Simon Willison's Blog（経緯の整理）
