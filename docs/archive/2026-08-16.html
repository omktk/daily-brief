SATELLITE Tech Solutions、スクール専用AI OS「KNOWLEDGE FORCE」にバックオフィス機能を追加

2026年8月15日公開

SATELLITEHOLDINGS株式会社は、スクール・教育事業者向けAI OS「KNOWLEDGE FORCE」に、 見積書・請求書・納品書の作成から電子契約までを担うバックオフィス機能を追加したと発表した。 AIチャットに話しかけるだけで請求元や発行日を反映した書類が自動生成されるほか、 既存の顧客管理機能と連携し、見積から請求・契約までの取引を顧客ごとに一元把握できる。 電子契約機能「ナレフォサイン」により契約締結までプラットフォーム上で完結し、 事業者がバックオフィス業務から解放され本業に集中できる環境を目指すという。

出典: PR TIMES（SATELLITEHOLDINGS株式会社）

中小企業の弱み診断ツール「企業機能マップ」を無償公開、外注依存を防ぐ経営の早見表

2026年8月15日配信（内容公開は8月14日）

トトノエルジャパン合同会社が運営する副業人材活用ラボは、中小企業の経営者や商工会議所などの 支援機関、金融機関向けに、企業機能を10の大分類・50の小分類に整理した無料診断ツール 「企業機能マップ」を公開した。症状から弱い機能を特定できる索引を備え、内製か外注かの 判断基準を提示するほか、経済産業省のローカルベンチマークとの対応表を用意し、生成AIによる 10〜15分程度の一次診断を可能にしている。200社以上の支援実績を持つ専門家が監修したという。

出典: PR TIMES（トトノエルジャパン合同会社）

Alibaba、270億パラメータのオープンモデル「Qwen3.8-27B」を公開　一部指標でOpus 4.6 Maxを上回る

2026年8月15日公開

Alibaba Cloudは、GPU1枚を積んだデスクトップPCでも動作する規模の言語モデル 「Qwen3.8-27B」の重みをHugging Face等で公開した。商用利用可能なApache 2.0ライセンスで 提供され、より大規模な「Qwen3.8-Max」は独自ライセンスで大規模商用利用に別途契約が必要 としている。ソフトウェア開発力を測る「SWE-bench Pro」で61.7、競技プログラミングの 「LiveCodeBench v6」で90.3を記録し、これらの指標では「Claude Opus 4.6 Max」を 上回ったが、科学的推論など複数の項目ではOpus 4.6 Maxに及ばないという。

出典: Hugging Face（Qwenモデルカード） / ITmedia AI+

Google、Gemini生成物の可視透かし表示をオン/オフ切り替え可能に

2026年8月14日発表

Googleは、画像生成「Nano Banana」・動画生成「Omni」・音楽生成「Lyria」で作成した コンテンツについて、目に見える透かし表示の有無を設定でユーザーが選べるようにしたと発表した。 Geminiアプリと動画編集ツール「Flow」から順次展開し、Search機能への対応も予定する。 可視透かしをオフにした場合でも、コンテンツ来歴を示す不可視の電子透かし「SynthID」と 「C2PA Content Credentials」メタデータは引き続き埋め込まれ、真正性の確認は可能なままとしている。 法律上の表示義務がある国・地域では本機能は提供されない。

出典: Google Gemini公式（X） / TechCrunch（二次情報）
