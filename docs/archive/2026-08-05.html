A. 日本のB2B/バーティカルSaaS・プロダクトマネジメント

ナレッジワーク、「セールスAIエージェントOS」の提供を開始。シリーズC 1stクローズで35億円を資金調達

2026年8月4日発表

株式会社ナレッジワークは、営業業務に特化したAIエージェント基盤「セールスAIエージェントOS」の提供を 開始したと発表した。企業ごとの営業データや戦略をAIが活用できるよう、オントロジー・ストラテジー・ AIエージェント・インターフェイスの4層で構成される。あわせてシリーズC 1stクローズ（第三者割当増資） で35億円を調達したことも明らかにした。国内大手企業を含む導入実績があるという。

出典: 株式会社ナレッジワーク 公式プレスリリース（PR TIMES）

GSI、ChatGPT・Claude・Geminiを"自社専用AI"にする企業向けプラットフォーム「CAP」を正式リリース

2026年8月4日発表

株式会社GSIは、複数の生成AIモデルを企業向けに統合するプラットフォーム「CAP（Custom AI Platform）」 を正式リリースした。社内文書を根拠に出典付きで回答する社内ヘルプ機能、最大3モデルの横並び比較、 資料の自動生成などを備え、テナント単位でデータを完全分離することでセキュリティを確保しているという。

出典: 株式会社GSI 公式プレスリリース（PR TIMES）

LayerX、AI人事労務サービス「バクラク人事労務」の先行トライアルを開始

2026年8月3日発表

株式会社LayerXは、労務手続きの自動化を目指すAIサービス「バクラク人事労務」の先行トライアルを 開始したと発表した。申請・承認・従業員マスタ更新・帳票作成を同一プラットフォーム上で完結させ、 マイナンバーカードから氏名・生年月日などを自動読み取りする機能も備える。中小企業から大企業まで バックオフィス業務の効率化を狙う。

出典: LayerX（バクラク）公式発表

B. AI/LLM・開発ツール

Anthropic、Claude Code v2.1.221を公開。VSCode向け「Focus view」やサンドボックス資格情報マスクを追加

2026年8月4日公開

Anthropicは開発者向けCLIツール「Claude Code」のv2.1.221をリリースした。ツール実行の詳細を折りたたみ 表示するVSCode向け「Focus view」、Linux/WSLのサンドボックス実行時に資格情報ファイルを実値に触れずに 扱う「mask」モードなどを追加。Bash・PowerShellツールの権限チェック回避の修正や、Windowsでの起動高速化 など多数の修正・改善も含まれる。

出典: Claude Code 公式changelog

GitHub、ノーコードAIアプリ構築ツール「GitHub Spark」の廃止を予告

2026年8月4日公開

GitHubは、github.com上のノーコードAIアプリ構築ツール「GitHub Spark」について、2026年8月4日付で 新規ユーザー登録と新規アプリ作成の受付を終了し、2026年8月31日までにアプリのエクスポートを求めると 発表した。AIモデルと開発ツールの進化により、VS CodeやCopilot CLIなど既存の開発環境でCopilotを 使う統合ワークフローへ移行が進んだことを理由に挙げている。既存アプリの稼働は継続するが、`llm()` 機能を使うアプリは別のAI推論プロバイダーへの置き換えが必要という。

出典: GitHub Changelog（公式）
