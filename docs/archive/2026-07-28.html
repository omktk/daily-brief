A. 日本のB2B/バーティカルSaaS・プロダクトマネジメント

レック・テクノロジー・コンサルティング、米RiverMeadow社製「AI主導型クラウド自動移行SaaS」の国内提供を開始

2026年7月27日 14:09発表

レック・テクノロジー・コンサルティング株式会社は、米RiverMeadow Software社とのリセール契約締結を発表。 仮想マシン移行と同時にOSの自動アップグレード・構成最適化を行う「Lift & Optimize」に対応し、 「移行コスト約1/3、期間約1/10」を掲げる。オンプレミス・各種パブリッククラウド間の相互移行に対応し、 まずAWSおよびHPE VM Essentialsへの移行から国内提供を開始する（提供開始は2026年7月15日）。

スタディスト、「Teachme Biz」導入によるジェイアンドシーの貿易実務標準化事例を公開

2026年7月27日 11:00発表

株式会社スタディストは、マニュアル作成・活用SaaS「Teachme Biz」を導入した株式会社ジェイアンドシーの 事例を公開。売上高が50億円から100億円へ急成長する過程で属人化していた貿易実務を標準化し、 社内問い合わせを1日約20件から5〜6件へ、ギフト商品発注書の作成時間を1件あたり1時間半から約40分へ 短縮したと報告している。

出典: 株式会社スタディスト 公式プレスリリース（PR TIMES）

B. AI/LLM・開発ツール

Moonshot AI、2.8兆パラメータの大規模モデル「Kimi K3」のオープンウェイトを公開

2026年7月26日公開

中国Moonshot AIは、フルパラメータ2.8兆（アクティブ約104B）・コンテキスト長100万トークンの 大規模言語モデル「Kimi K3」の重みを「Kimi K3 License」のもとHugging Face上で公開した。 同社は「世界初のオープンな3T級モデル」としており、研究・デプロイ・独自ホスティングでの利用を想定している。 MXFP4形式でも重みのサイズは約1.4TBに達するとされ、動作には相応の計算資源が必要になる。

出典: Hugging Face上のMoonshot AI公式モデルページ

GitHub、Copilotアプリのアクセス管理を専用ポリシーとして分離

2026年7月27日公開

GitHub Changelogによると、これまでCopilot CLIのポリシーに依存していたCopilotアプリの アクセス制御が、独立したポリシーとして管理できるようになった。エンタープライズ・組織管理者は 「Enabled everywhere」「Disabled everywhere」「Let organizations decide」の3択で アプリの利用可否を設定できる。デフォルトは全員利用可能。

出典: GitHub Changelog（公式）
