freee、税理士事務所向けAIエージェント「freee顧問先管理」と「freee Agent Hub」をfAD2026にて公開

2026年8月7日発表

フリー株式会社は、税理士事務所向けに資料回収から決算申告までをAIで一気通貫に支援する 「freee顧問先管理 | AIエージェント」（記帳・ルール整理・月次チェック・申告書チェックの 4つのプリセットエージェント）と、事務所ごとの独自ルールに合わせてAIエージェントを構築できる ノーコード基盤「freee Agent Hub」を発表した。申告書チェックエージェントは8月28日から無償提供、 有償サービスは9月15日開始予定。

輸出管理AIのTIMEWELL、ISMS認証「ISO/IEC 27001」を取得

2026年8月7日18:30発表

株式会社TIMEWELLは、自社の安全保障輸出管理AIエージェント「TRAFEED」に関する情報セキュリティ マネジメントシステムについて、ISO/IEC 27001:2022認証（SGSジャパン認証）を取得したと発表した。 TRAFEEDは製品仕様・技術情報・取引先情報など機微情報を扱う輸出該非判定業務を支援するサービスで、 複数の大規模言語モデルを組み合わせて判定精度95%超を実現しているとしている。

SIGQ、インシデント対応の成熟度を無料で診断できるWebページを公開

2026年8月7日11:58発表

株式会社SIGQは、企業のインシデント対応体制の成熟度をNIST CSF・ISO/IEC 27001:2022・SOC 2に 基づく15問・約3分のセルフ診断で可視化できる無料Webツール「インシデント対応 成熟度クイック診断」 を公開した。会員登録不要で、11カテゴリを横断して弱点領域を提示する。「インシデント対応の 属人化」（回答企業の72.0%が1〜2名に集中と回答）という課題意識を背景としている。

出典: 株式会社SIGQ 公式プレスリリース（PR TIMES）

Anthropic、Claude Code v2.1.224をリリース

2026年8月7日公開

Anthropicは「Claude Code」の新バージョン2.1.224を公開した。Team/Enterprise向けに `claude self-hosted-runner`によるセルフホスト環境、エージェント間で直接メッセージを やり取りできるクロスセッション`SendMessage`（macOS/Linux）、サンドボックスでの認証情報 マスキング設定（JWTデコードやAWS署名鍵の検出等）を追加。セッションあたり200体だった サブエージェント起動数の上限も撤廃した。長いプロジェクトパスでのセッションディレクトリ 誤解決や、サンドボックスの末尾スラッシュ付きdenyルールが回避可能だった不具合等も修正している。

出典: Claude Code 公式チェンジログ

GitHub Copilot、コードレビューの「Effort Levels」を一般提供開始

2026年8月7日公開

GitHubは、Copilotコードレビューのレビュー深度を選べる「Lite」「Balanced」の2段階 （プレビュー時の「Low」「Medium」から改称）を一般提供開始したと発表した。Liteはドキュメント 修正等の単純な変更向け、Balancedはセキュリティに関わる複雑な変更向けに高推論モデルで 深く分析する。組織単位で既定値を設定でき、レビュー単位で個別に選択も可能。 Copilot Pro/Pro+/Max/Business/Enterprise向け。

GitHub、Copilot利用状況メトリクスAPIにエージェントアプリ別の活動データを追加

2026年8月7日公開

GitHubは、Copilot利用状況メトリクスAPIに`totals_by_3rd_party_agent`配列を追加したと発表した。 Claude・Codex等のパートナー製エージェントアプリごとにID・利用回数・セッション数を区別して 取得できるようになり、これまで単一の指標に混在していたエージェント活動を個別に比較・分析 できる。Enterprise/Organizationの1日・28日レポートで、管理権限を持つユーザーが利用可能。
