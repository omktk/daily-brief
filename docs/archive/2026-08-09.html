A. 日本のB2B/バーティカルSaaS・プロダクトマネジメント

Notion、Shareメニューから直接Custom Agentへ共有できる機能を追加

2026年8月7日公開

Notionは公式リリースノートで、ドキュメントやデータベースを「Share」メニューから 直接Custom Agentに共有できる新機能を発表した。従来はエージェント設定画面まで移動して 共有先を追加する必要があったが、この変更により共有操作が簡略化される。同社は7月31日にも 「AI Meeting Note完了後にCustom Agentを自動実行する」機能を追加しており、 エージェント関連機能の拡充が続いている。

B. AI/LLM・開発ツール

GitHub Copilot週次リリースまとめ: VS Code 1.132・Copilotアプリ・CLIの新機能

2026年8月7日公開

GitHub公式ブログが週次のCopilotアップデートをまとめて公開した。Copilotアプリでは各リクエストを 処理したモデルを表示する「Auto」機能、共有セッションへの直接アクセス、`/side`コマンドでの 並行質問が可能になった。Copilot CLIはセッションサイドバーでの複数セッション管理、独立した 作業環境を作る新しい`/worktree`コマンド、Gitなしで変更を取り消せる`/rewind`コマンドに対応。 VS Code 1.132ではブラウザでの要素レベルフィードバック、多言語音声入力、`/btw`コマンドでの サイドチャット起動、Markdown差分表示の改善が追加された。

出典: GitHub Changelog 公式ブログ

Claude Code、v2.1.225 / v2.1.226をリリース

2026年8月8日公開

Anthropicは「Claude Code」のv2.1.225とv2.1.226を公開した。v2.1.225では、ゲートウェイの 支出上限に達した際に上限額・リセット時刻・運用者メッセージを表示する機能と、信頼されていない ディレクトリを開いた際のワークスペース信頼プロンプトを追加。長寿命OAuthトークン置換直後に 発生していた一時的な401エラーや、macOSでキーチェーン読み取りがタイムアウトした後にMCPの OAuthサーバーで間欠的に401エラーが出る不具合を修正した。v2.1.226では追加のバグ修正と 信頼性改善が行われたが、公式チェンジログに個別項目の詳細記載はない。
