GitHub Copilotに新モデル「MAI-Code-1.1-Flash」が追加、旧モデルは廃止予告

2026年8月11日公開

GitHubは公式チェンジログで、Microsoftの小型コーディングモデル 「MAI-Code-1.1-Flash」がGitHub Copilotで利用可能になったと発表した。画像理解の ネイティブビジョン対応やコード品質・命令追従性の向上が図られ、旧モデル比で価格が 73%低下した。Copilot Free/Studentでは自動選択され、Pro/Business/Enterprise利用者は 手動選択が可能。あわせて旧モデル「MAI-Code-1-Flash」を2026年9月10日付で全体験から 廃止すると予告しており、Enterprise/Business管理者は新モデルの有効化対応が必要となる。

出典: GitHub Changelog（提供開始）／同（廃止予告）

Anthropic、EU AI法対応でClaudeの生成テキストに透かしを付与へ

2026年8月11日公開

Anthropicは、EU AI法の透明性規約(Code of Practice)への署名に基づき、2026年8月2日 以降にリリースされたClaudeモデルが生成するテキストに、知覚できない透かしを組み込むと 発表した。コピー＆ペースト後もテキストに追従し、一部編集を経ても残存し得るとしている。 画像などのファイルにはC2PA標準による署名付き来歴メタデータを付与する。対象はClaude、 Claude Platform（API）、Claude Code、Claude Coworkなど主要製品全般。透かしが検出 されないことは人間作成の証明にはならないという限界も明記されている。
