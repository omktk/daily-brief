A. 日本のB2B/バーティカルSaaS・プロダクトマネジメント

freee、富士フイルムビジネスイノベーションと協業しSaaS管理サービス「IT Expert Services SaaS管理」を提供開始

2026年7月22日発表（サービス提供は7月13日開始）

freeeは富士フイルムビジネスイノベーションと協業し、企業内で利用が広がるSaaSの管理を支援する サービスの提供を開始したと発表。シャドーIT・未管理SaaSの増加に伴うセキュリティリスクや、 従業員の入退社に連動したアカウントのライフサイクル管理の負担といった、中堅・中小企業が抱える 課題への対応をうたう。

B. AI/LLM・開発ツール

GitHub Copilot、「Claude Opus 5」の利用に対応

2026年7月24日

GitHubは、AnthropicのモデルClaude Opus 5をGitHub Copilotのモデル選択肢に追加したと発表。 VS Code・Visual Studio・JetBrains系IDE・Xcodeなどで、Copilot Pro+ / Business / Enterprise 等の 対象プランから選択可能。複数手順にまたがる自律的なコード修正や、変更内容の検証を伴う 長時間タスク向けと位置づけられている。高リスクなサイバー関連の要求は一部ブロックされる 保護機能も備えるという。段階的なロールアウト中で、Enterprise/Business管理者は設定での有効化が必要。

出典: GitHub Changelog（公式）
