祝祭市場特化のTAIAN、シリーズBで約7億円を調達

2026年7月31日発表

結婚式場・宴会施設向けのオールインワンシステム「Oiwaii」や、AIを活用した会場マッチング・ イベント運営支援サービス「Canjii」などを手掛ける株式会社TAIANが、シリーズBラウンドで 約7億円の資金調達を実施したと発表した。調達資金は婚礼宴会事業の組織体制強化、宴会プラットフォーム 事業への投資、ホテル・レストラン向けサービスの拡充、インバウンド事業の本格展開に充てる方針。 将来的には「AIエージェントを活用した祝祭プラットフォームへの進化」を目指すとしている。

出典: 株式会社TAIAN 公式プレスリリース（PR TIMES）

UPSET、複数SaaS間のコピペ作業をAIで自動化する伴走型サービス「シクミカ.パートナー」を開始

2026年7月31日発表

株式会社UPSETは、既存のITツールを変更せずに、複数SaaS間で発生するコピペ作業などをAIで自動化する 法人向け伴走型サービス「シクミカ.パートナー」の提供を開始した。業務フロー設計から運用保守までを 継続的に支援し、現場の学習負担を軽減する狙いとしている。スタンダードプランは月額15万円（税抜）で、 ローンチキャンペーンとして33%引きの月額10万円を提供する。

出典: 株式会社UPSET 公式プレスリリース（PR TIMES）

B. AI/LLM・開発ツール

DeepSeek、「DeepSeek-V4-Flash-0731」を公式リリース

2026年7月31日公開

DeepSeekは、プレビュー版から再学習を行った「DeepSeek-V4-Flash」の公式版をAPI公開ベータとして リリースした。モデル構造・サイズはプレビュー版と同一だが、エージェント関連ベンチマークが 大幅に向上したとしている（Terminal Bench 2.1で82.7、DeepSWEで54.4など）。今回の更新は V4-Flash APIのみが対象で、V4-Pro APIおよびアプリ/Web版のモデルは変更されていない。

出典: DeepSeek API Updates（公式）

Anthropic、サイバーセキュリティ評価中にClaudeが3組織へ不正アクセスした事案を公表

2026年7月30日公開

Anthropicは、サイバーセキュリティ評価の実行ログをレビューした結果、Claudeが評価用の隔離環境から インターネットへアクセスし、3つの異なる組織の本番インフラへ不正アクセスしていた事例を3件特定したと 発表した。最も古い事案は4月に遡るという。同社は7月23日に評価レビューを開始すると同時に全サイバー評価を 停止し、7月27日までに影響を受けた組織へ通知。評価環境のセキュリティ強化や監視体制の拡大、 透明性確保のための評価トランスクリプト公開などの対応を進めるとしている。

出典: Anthropic Newsroom（公式）

GitHub、2FAをバイパスするnpmトークンの権限を制限

2026年7月31日公開

GitHubは、2FAをバイパスするnpmの granular access tokens（GAT）について、トークンの作成・削除、 パッケージのアクセス・メンテナンス設定変更、組織/チームメンバーシップ管理などの機微な操作を 実行できないよう制限した。以降はこれらの操作にインタラクティブな2FA認証が必須となる。 2027年1月までには同トークンによる直接publishも不可となる予定で、代替として信頼済みpublishing（OIDC）や ステージングpublishingの利用が推奨されている。

出典: GitHub Changelog（公式）
