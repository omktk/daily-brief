A. 日本のB2B/バーティカルSaaS・プロダクトマネジメント

SmartHR、ID・アクセス管理（IAM）領域に本格参入

2026年7月28日発表二次情報

株式会社SmartHRは、情報システム部門向けソリューションを強化し、「ID・アクセス管理（IAM）」領域に 本格参入すると発表した。2025年から提供する「ID管理」機能を土台に、①外部サービス利用の把握・検知、 ②アカウント管理の高度化、③アクセス管理の強化、の3施策を推進する方針。7月15日から先行提供している 「シャドーIT検知」機能を皮切りに、人事・労務データと連動したアカウント・アクセス管理へ発展させるとしている。 公式プレスリリースの直接URLを確認できなかったため、報道記事を出典とする。

出典: クラウド Watch（Impress）

アピリッツ、サイト内検索「Advantage Search」に生成AI活用の類似商品レコメンド機能を追加

2026年7月30日発表

株式会社アピリッツは、EC・Webサイト向けの自動学習型サイト内検索エンジン「Advantage Search」に、 新機能「ゼロヒット検索 類似商品レコメンドAI」を追加した。該当商品が見つからない検索キーワードを 生成AIが読み替え、関連商品を自動で提示する。おすすめ商品の設定・更新や検索データ分析にかかる 運用負荷を軽減する狙いとしている。

出典: 株式会社アピリッツ 公式プレスリリース（PR TIMES）

B. AI/LLM・開発ツール

GitHub Copilot for Visual Studio、Copilot SDKベースの新エージェントをプレビュー公開

2026年7月30日公開

GitHubは、Visual Studio向けGitHub Copilotの7月アップデートを公開した。GitHub Copilot CLIと同じ Copilot SDKを基盤とする新しいエージェント（プレビュー）をChatのエージェント選択に追加し、 より少ない往復でタスクを完了できるよう設計されている。.NET/Azureチーム作成の組み込みスキルの統合、 エディタ上で選択したコードをレビューできる「Copilot Actions」、組織全体のカスタム指示を一元管理できる 機能（Business/Enterprise向け）なども追加された。

出典: GitHub Changelog（公式）

GitHub、「スタック型プルリクエスト」を公開プレビューとして提供開始

2026年7月30日公開

GitHubは、大規模な変更を依存関係のある複数の小さなプルリクエストに分割して管理できる 「スタック型プルリクエスト」機能を公開プレビューとして提供開始した。各層を独立してレビューでき、 複数層をまとめて1回のマージで統合することも可能。CLI拡張機能、github.com、モバイルアプリで 利用できる。

出典: GitHub Changelog（公式）

OpenAI、GPT-5.6の値下げとAPI「Fast mode」を導入

2026年7月30日公開

OpenAIはAPI変更履歴で、GPT-5.6シリーズの料金引き下げ（Lunaは80%減、Terraは20%減）と、 従来のPriority Processingに代わる新しい高速処理オプション「Fast mode」の提供開始を発表した。 Fast modeは標準処理と比べて最大2.5倍高速な一方、料金は2倍になるとしている。

出典: OpenAI API Changelog（公式）
